# Hotel Booking Analysis using Python

## Overview

This project performs exploratory data analysis on hotel booking data to uncover customer behavior, booking trends, cancellation patterns, and business insights.

---

## Problem Statement

Hotel booking cancellations create major revenue loss for hotels. This project aims to analyze booking patterns and identify factors contributing to cancellations.

---

## Objectives

* Analyze booking behavior
* Identify cancellation trends
* Discover seasonal patterns
* Understand customer preferences
* Generate business insights

---

## Dataset Information

The dataset includes:

* Booking dates
* Hotel type
* Customer details
* Stay duration
* Cancellation status
* Market segment

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Project Workflow

1. Data Cleaning
2. Data Preprocessing
3. Exploratory Data Analysis
4. Visualization
5. Business Insight Generation

---

## Key Insights

* Cancellation rates are higher for certain market segments
* Seasonal demand affects booking behavior
* City hotels experience different trends than resort hotels
* Lead time strongly influences cancellations
